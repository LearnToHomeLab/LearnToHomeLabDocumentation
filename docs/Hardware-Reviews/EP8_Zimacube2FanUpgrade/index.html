Zimacube 2 Cooling Fan Upgrade (Noctua)

Hey guys, in todays video I am going to show you how to upgrade your Zimacube 2 with much quieter cooling fans to get rid of that annoying hum/buzz, as well as two ways to control the fan speed.

Useful Links​

  1. Extra deep rear fan grill by TommyDaDog
  2. Standard depth rear fan grill for 25mm fans and below by Marcol123
  3. Noctua NF-A8 PWM Fan I recommend this fan because its insanely quite and great quality.

Your options​

So you will have two options to accomplish the same goal here, and that is to quite down your NAS.

  1. Use the built in BIOS sys_fan settings, but this is not dynamic. What I mean by this is you set a set speed that is tolerable and also keeps your fans cool enough under their heaviest load. We did it this way and recommend the Noctua NF-A8 PWM Fan
  2. You can read more on the two script options below which will see the temperature of the drives and spin the fans up or down based on their reported temperature, however this way is less fool proof. It may require some trial and error and may or may not work depending on what operating system you are running but I did do my best to make the script work on any Zimaboard 2.

How We Did it Using Sys_fan​

So to keep it as fool proof for everyone, we recommend you purchase the two Noctua NF-A8 PWM Fan and use one of their 4 pin Y splitter cables.

Then plug in two 4 pin extension cables.

Feed them down through the side whole that also feeds a power supply cable down to the SATA backplane.

Then you will plug your two fans into those 4 pin extension cables.

Put everything back together.

turn the device on and enter the BIOS by spamming the ESC key.

In the BIOS go to the advanced tab.

Then hardware monitor.

Inside of hardware monitor, you will adjust system fan select section.

Set it to manual mode.

Then set it to PWM setting: 125 which is 50% fan speed.

Then monitor your hard drive temperature to ensure they are not getting above 55-60C, but in my experience this will keep them around 32C in a room that is set to 70F or 21C.

First Script Option​

This is a script I specifically created myself. You can pick between 10% fan speed and 100% fan speed. This script also works with TrueNAS (confirmed) and with the Noctua Fans mentioned above on a Zimacube 2.

Testing Fan Speeds and Noise:​

To test your fans and the noise, you can use the below script within the TrueNAS shell. Just re-run the script and type between 10% and 100%, this will allow you to set your fans to a tolerable sound level for you:

sudo bash -c '
modprobe i2c-dev || exit 1

BUS=""

for b in 0 1 2 3 4; do
    [ -e "/dev/i2c-$b" ] || continue

    R=$(i2cdetect -y "$b" 0x69 0x69 2>/dev/null || true)

    if echo "$R" | grep -qE "(^|[[:space:]])69([[:space:]]|$)"; then
        BUS="$b"
        break
    fi
done

if [ -z "$BUS" ]; then
    echo "ERROR: ZimaCube 2 fan controller not found."
    exit 1
fi

echo
echo "========================================"
echo " ZimaCube 2 Rear HDD Fan Control"
echo "========================================"
echo
echo "Controller found:"
echo "  I2C Bus: $BUS"
echo "  Address: 0x69"
echo
echo "Fan speed range: 10% - 100%"
echo
echo "  10%  = quietest tested setting"
echo "  25%  = low"
echo "  50%  = medium"
echo "  60%  = original ZimaCube setting"
echo "  75%  = high"
echo "  100% = maximum"
echo
echo "NOTE: 0% is intentionally unavailable because"
echo "raw value 0 caused the controller to run the fans at maximum."
echo

read -p "Enter fan speed (10-100%): " SPEED

case "$SPEED" in
    ""|*[!0-9]*)
        echo "ERROR: Enter a number from 10 to 100."
        exit 1
        ;;
esac

if [ "$SPEED" -lt 10 ] || [ "$SPEED" -gt 100 ]; then
    echo "ERROR: Fan speed must be between 10 and 100."
    exit 1
fi

TARGET="$SPEED"
HEX=$(printf "%02X" "$TARGET")

echo
echo "Setting rear HDD fan level to ${SPEED}%..."
echo "Controller value: $TARGET (0x$HEX)"

if i2cset -f -y "$BUS" 0x69 \
0x04 0x01 "0x$HEX" 0x00 0x00 0x00 0x00 0x01 0x00 i
then
    echo
    echo "SUCCESS: Rear HDD fan level set to ${SPEED}%."
else
    echo
    echo "ERROR: Failed to communicate with the fan controller."
    exit 1
fi
'

Setting a repeatable script​

Now you have determined the speed at which you want your fans to run each time TrueNAS boots, we need to create a script that is ran on every reboot of TrueNAS.

The script below by default is set to 60%. You want to change the SPEED=60 line at the top of the script to whatever fan speed you choose.

In the shell you need to create a directory and the file to paste the below script into. Make sure you change to your data pool name in the command below (your pool name):

sudo mkdir -p "/mnt/(your pool name)/scripts" && sudo nano "/mnt/(your pool name)/scripts/zimacube-fans.sh"

Then paste in that file:

#!/bin/bash

# ZimaCube 2 rear HDD fan controller
# Default controller value: 60 / 0x3C
# This matches the original ZimaCube-provided setting.

SPEED=60

modprobe i2c-dev || exit 1

BUS=""

for b in 0 1 2 3 4; do
    [ -e "/dev/i2c-$b" ] || continue

    R=$(i2cdetect -y "$b" 0x69 0x69 2>/dev/null || true)

    if echo "$R" | grep -qE "(^|[[:space:]])69([[:space:]]|$)"; then
        BUS="$b"
        break
    fi
done

if [ -z "$BUS" ]; then
    echo "ERROR: ZimaCube 2 fan controller not found."
    exit 1
fi

HEX=$(printf "%02X" "$SPEED")

echo "ZimaCube 2 fan controller found on bus $BUS."
echo "Applying rear HDD fan setting: $SPEED (0x$HEX)"

if i2cset -f -y "$BUS" 0x69 \
0x04 0x01 "0x$HEX" 0x00 0x00 0x00 0x00 0x01 0x00 i
then
    echo "SUCCESS: ZimaCube 2 rear HDD fan setting applied."
else
    echo "ERROR: Failed to communicate with fan controller."
    exit 1
fi

Then you need to make the script executable: Make sure you change to your data pool name in the command below (your pool name)

sudo chmod +x "/mnt/(your pool name)/scripts/zimacube-fans.sh"

You can then manually test your script with:

sudo "/mnt/(your pool name)/scripts/zimacube-fans.sh"

Add the ZimaCube 2 Fan Script to TrueNAS Startup​

In the TrueNAS web interface, go to:

System → Advanced Settings → Init/Shutdown Scripts → Add

Configure the new startup script with the following settings:

SettingValue
DescriptionZimaCube 2 HDD Fan Control
TypeScript
Script/mnt/(your pool name)/scripts/zimacube-fans.sh
WhenPost Init
Timeout30
EnabledYes

Click Save.

After this is configured, TrueNAS should automatically run the fan-control script every time the system boots.

The startup process will look like this:

TrueNAS boots
      ↓
Post Init runs
      ↓
zimacube-fans.sh starts
      ↓
i2c-dev loads
      ↓
script searches I2C buses 0–4
      ↓
ZimaCube controller at 0x69 is detected
      ↓
controller value 60 / 0x3C is applied
      ↓
rear HDD fan control is initialized

The script automatically searches for the 0x69 controller instead of permanently assuming it will always be on I2C bus 0.

Then save it.

Second Script Option (Automatic Fan Speed)​

This second option automatically adjusts the rear HDD fan speed based on the temperature of the hottest hard drive in your ZimaCube 2.

The script checks the HDD temperatures every 30 seconds and automatically increases or decreases the fan setting as the drive temperatures change.

By default, the fan curve is configured like this:

Hottest HDD TemperatureFan Setting
30°C or below30%
31°C34%
32°C38%
33°C42%
34°C46%
35°C50%
36°C54%
37°C58%
38°C62%
39°C66%
40°C70%
41°C74%
42°C78%
43°C82%
44°C86%
45°C or above90%

Between 30°C and 45°C, the fan setting increases linearly.

This allows the fans to remain quieter while the drives are cool and automatically increase airflow as HDD temperatures rise.

If the script cannot read any HDD temperatures, it uses a 100% failsafe fan setting.

Creating the Dynamic Fan Script​

First, create a scripts directory on your TrueNAS storage pool and create the dynamic fan-control script.

Replace (your pool name) with the name of your TrueNAS storage pool:

sudo mkdir -p "/mnt/(your pool name)/scripts" && sudo nano "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.sh"

For example, if your pool is named tank, you would use:

sudo mkdir -p "/mnt/tank/scripts" && sudo nano "/mnt/tank/scripts/zimacube-fans-dynamic.sh"

Then paste the following script into the file:

#!/bin/bash

# ============================================================
# ZimaCube 2 Dynamic Rear HDD Fan Controller
#
# Monitors the hottest HDD temperature and automatically
# adjusts the ZimaCube 2 rear HDD fan setting.
#
# Fan curve:
#   30C or below = 30%
#   35C          = 50%
#   40C          = 70%
#   45C or above = 90%
#
# If HDD temperatures cannot be read:
#   Failsafe = 100%
# ============================================================

PATH=/usr/sbin:/usr/bin:/sbin:/bin

MIN_TEMP=30000
MAX_TEMP=45000

MIN_SPEED=30
MAX_SPEED=90
FAILSAFE_SPEED=100

# Check HDD temperatures every 30 seconds.
INTERVAL=30

# Store the log in the same directory as this script.
SCRIPT_DIR="${0%/*}"
LOG_FILE="$SCRIPT_DIR/zimacube-fans-dynamic.log"

log_message() {
    echo "$(date '+%Y-%m-%d %H:%M:%S') | $*" >> "$LOG_FILE"
}

find_controller() {
    BUS=""

    # Load Linux I2C userspace support.
    modprobe i2c-dev 2>/dev/null || return 1

    # Search I2C buses 0 through 4 for the
    # ZimaCube backplane controller at address 0x69.
    for b in 0 1 2 3 4; do
        [ -e "/dev/i2c-$b" ] || continue

        R=$(i2cdetect -y "$b" 0x69 0x69 2>/dev/null || true)

        if echo "$R" | grep -qE '(^|[[:space:]])69([[:space:]]|$)'; then
            BUS="$b"
            return 0
        fi
    done

    return 1
}

get_hottest_drive() {
    HOTTEST=-1
    DRIVE_COUNT=0

    # Search Linux hwmon for HDD temperature sensors.
    for h in /sys/class/hwmon/hwmon*; do
        [ -r "$h/name" ] || continue
        [ "$(cat "$h/name")" = "drivetemp" ] || continue
        [ -r "$h/temp1_input" ] || continue

        TEMP=$(cat "$h/temp1_input" 2>/dev/null)

        case "$TEMP" in
            ""|*[!0-9]*) continue ;;
        esac

        DRIVE_COUNT=$((DRIVE_COUNT + 1))

        # Use the hottest drive rather than an average.
        if [ "$TEMP" -gt "$HOTTEST" ]; then
            HOTTEST="$TEMP"
        fi
    done
}

calculate_speed() {
    # If no HDD temperatures are available, use the failsafe.
    if [ "$DRIVE_COUNT" -eq 0 ] || [ "$HOTTEST" -lt 0 ]; then
        SPEED="$FAILSAFE_SPEED"
        TEMP_DISPLAY="NO SENSOR"

    # 30C or below = 30%.
    elif [ "$HOTTEST" -le "$MIN_TEMP" ]; then
        SPEED="$MIN_SPEED"
        TEMP_DISPLAY="$((HOTTEST / 1000))C"

    # 45C or above = 90%.
    elif [ "$HOTTEST" -ge "$MAX_TEMP" ]; then
        SPEED="$MAX_SPEED"
        TEMP_DISPLAY="$((HOTTEST / 1000))C"

    # Linear fan curve between 30C and 45C.
    else
        SPEED=$((MIN_SPEED + ((HOTTEST - MIN_TEMP) * (MAX_SPEED - MIN_SPEED) / (MAX_TEMP - MIN_TEMP))))
        TEMP_DISPLAY="$((HOTTEST / 1000))C"
    fi
}

set_fans() {
    HEX=$(printf "%02X" "$SPEED")

    i2cset -f -y "$BUS" 0x69 \
        0x04 0x01 "0x$HEX" \
        0x00 0x00 0x00 0x00 \
        0x01 0x00 i
}

log_message "Starting ZimaCube 2 dynamic HDD fan controller."

# Wait until the ZimaCube fan controller is available.
while ! find_controller; do
    log_message "WARNING: ZimaCube controller 0x69 not found. Retrying in 10 seconds."
    sleep 10
done

log_message "ZimaCube controller detected on I2C bus $BUS."

LAST_SPEED=-1

while true; do
    get_hottest_drive
    calculate_speed

    # Only send another I2C command if the calculated
    # fan setting has changed.
    if [ "$SPEED" -ne "$LAST_SPEED" ]; then
        if set_fans; then
            log_message "Hottest HDD: $TEMP_DISPLAY | Fan setting: ${SPEED}%"
            LAST_SPEED="$SPEED"
        else
            log_message "ERROR: Failed to communicate with fan controller."
            LAST_SPEED=-1
        fi
    fi

    sleep "$INTERVAL"
done

Save the Script​

After pasting the script into Nano, save it by pressing:

Ctrl + O

Then press:

Make the Script Executable​

The script needs executable permissions.

Replace (your pool name) with your TrueNAS storage pool name:

sudo chmod +x "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.sh"

You can verify the permissions with:

ls -l "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.sh"

You should see executable permissions similar to:

-rwxr-xr-x

Manually Test the Dynamic Fan Controller​

Before configuring the script to run continuously, test it directly in the TrueNAS shell.

Run:

sudo /bin/bash "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.sh"

The script runs in the foreground and writes its activity to a log file, so the shell may appear to simply sit there while it is running.

Allow it to run for at least 30 to 60 seconds.

Then press:

Ctrl + C

to stop the manual test.

Now view the log:

cat "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.log"

You should see output similar to:

2026-11-11 13:46:17 | Starting ZimaCube 2 dynamic HDD fan controller.
2026-11-11 13:46:17 | ZimaCube controller detected on I2C bus 0.
2026-11-11 13:46:17 | Hottest HDD: 38C | Fan setting: 62%
2026-11-11 13:46:48 | Hottest HDD: 39C | Fan setting: 66%

This confirms that the script:

  • detected the ZimaCube fan controller
  • detected the HDD temperature sensors
  • selected the hottest HDD
  • calculated the correct fan setting
  • sent the new setting to the ZimaCube fan controller

Test the Dynamic Controller as a System Service​

The dynamic script needs to run continuously in the background.

Instead of having the script attempt to background itself, we use systemd-run to create a temporary system service that owns the continuously running fan controller.

First, make sure an old test service is not already running:

sudo systemctl stop zimacube-fans-dynamic.service 2>/dev/null || true

Clear the old test log so the next output is easy to verify:

sudo truncate -s 0 "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.log"

Now start the dynamic fan controller as a systemd service:

sudo systemd-run \
  --unit=zimacube-fans-dynamic \
  --property=Restart=always \
  --property=RestartSec=10 \
  /bin/bash "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.sh"

You should see:

Running as unit: zimacube-fans-dynamic.service

Verify the Dynamic Fan Service​

Check the service:

sudo systemctl status zimacube-fans-dynamic.service --no-pager

You should see:

Active: active (running)

The process list should also show the Bash script and its 30-second sleep cycle, similar to:

/bin/bash /mnt/(your pool name)/scripts/zimacube-fans-dynamic.sh
sleep 30

Now check the fan-controller log:

cat "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.log"

You should see something similar to:

2026-11-11 13:48:19 | Starting ZimaCube 2 dynamic HDD fan controller.
2026-11-11 13:48:19 | ZimaCube controller detected on I2C bus 0.
2026-11-11 13:48:19 | Hottest HDD: 39C | Fan setting: 66%
2026-11-11 13:48:50 | Hottest HDD: 38C | Fan setting: 62%
2026-11-11 13:49:20 | Hottest HDD: 39C | Fan setting: 66%
2026-11-11 13:49:50 | Hottest HDD: 38C | Fan setting: 62%

You can also watch the log live with:

tail -f "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.log"

Press:

Ctrl + C

to exit the log viewer.

This only stops tail. It does not stop the dynamic fan controller.

Why We Use systemd-run​

The fan controller is designed to run continuously.

During testing, attempting to launch the continuous monitoring loop directly in the background from the TrueNAS startup environment caused commands such as grep, date, and sleep to fail.

Using systemd-run solves this by allowing systemd to take ownership of the long-running process.

The startup process becomes:

TrueNAS Post Init
      ↓
systemd-run
      ↓
zimacube-fans-dynamic.service
      ↓
zimacube-fans-dynamic.sh
      ↓
monitor HDD temperatures every 30 seconds
      ↓
adjust rear HDD fans

The systemd service is configured with:

Restart=always
RestartSec=10

This also means that if the fan-control script unexpectedly exits, systemd attempts to restart it after 10 seconds.

Add the Dynamic ZimaCube 2 Fan Controller to TrueNAS Startup​

The systemd service created above is a transient service. It exists for the current boot but is not permanently saved by systemd.

To recreate it automatically every time TrueNAS boots, use a TrueNAS Post Init Command.

In the TrueNAS web interface, go to:

System → Advanced Settings → Init/Shutdown Scripts → Add

Configure the startup entry with the following settings:

SettingValue
DescriptionZimaCube 2 Dynamic HDD Fan Control
TypeCommand
WhenPost Init
Timeout30
EnabledYes

For the Command, enter the following as one line.

Replace (your pool name) with the name of your TrueNAS storage pool:

/usr/bin/systemd-run --unit=zimacube-fans-dynamic --property=Restart=always --property=RestartSec=10 /bin/bash "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.sh"

Click Save.

Important: For the dynamic fan controller, select Command, not Script. The TrueNAS startup command creates the systemd service, and systemd then runs the continuous monitoring script.

Verify Everything After a Reboot​

After adding the TrueNAS Post Init Command, reboot the ZimaCube 2.

Once TrueNAS finishes booting, open the shell and check the service:

sudo systemctl status zimacube-fans-dynamic.service --no-pager

You should see:

Active: active (running)

Then check the fan-controller log:

tail -20 "/mnt/(your pool name)/scripts/zimacube-fans-dynamic.log"

You should see new entries from the current boot similar to:

2026-11-11 13:48:19 | Starting ZimaCube 2 dynamic HDD fan controller.
2026-11-11 13:48:19 | ZimaCube controller detected on I2C bus 0.
2026-11-11 13:48:19 | Hottest HDD: 39C | Fan setting: 66%

At this point, the dynamic fan controller is automatically running after every TrueNAS reboot.

How the Dynamic Fan Controller Works​

The script automatically searches I2C buses 0-4 for the ZimaCube backplane controller at address 0x69, rather than permanently assuming that it will always be located on I2C bus 0.

It then searches the Linux hardware-monitoring interfaces for drives using the drivetemp sensor.

Rather than averaging all HDD temperatures, the script finds the hottest HDD and bases the fan setting on that drive.

For example:

HDD 1: 32C
HDD 2: 34C
HDD 3: 39C
HDD 4: 35C
HDD 5: 33C

The script uses:

39C

which results in:

66%

If the hottest HDD later drops to:

38C

the fan setting automatically changes to:

62%

If the script cannot read any HDD temperature sensors, it requests the 100% failsafe fan setting.

This allows the ZimaCube 2 rear HDD fans to continuously respond to actual HDD temperatures instead of running at one fixed setting all the time.
