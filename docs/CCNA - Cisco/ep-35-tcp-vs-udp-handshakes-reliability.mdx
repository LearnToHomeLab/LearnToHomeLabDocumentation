### Evaluate Packet Headers and Protocol Interactions
> Trace frame and packet headers across Layers 1 through 4 to understand protocol handshakes, addressing boundaries, and transmission parameters.

Used to predict traffic forwarding decisions and interpret network analyzer captures.

```cisco
! Verification and evidence collection
Router# show interfaces
Router# show ip arp
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show interfaces` | Verify operational status, administrative flags, and active state |

```cisco
Device# show interfaces
! Confirm operational readiness and healthy state
```

### Diagnose Layer 1 and Layer 2 Operational Faults
> Audit physical interface counters, duplex mismatches, and address resolution failures using Cisco IOS diagnostic commands.

Primary troubleshooting workflow when resolving link flapping, packet drops, or endpoint isolation.

<WarningBox>
  Always verify that configuration changes are committed to NVRAM using 'copy running-config startup-config'. Mismatched parameters, unassigned VLANs, or missing 'no shutdown' commands will disrupt link forwarding.
</WarningBox>
