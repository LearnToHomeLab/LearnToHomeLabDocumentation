### Connect to a New Switch via Out-of-Band Console
> Establish physical communication using a rollover or USB console cable connected to the switch's RJ-45 or USB mini-B console port at 9600-8-N-1 settings.

Required when unboxing brand new equipment or recovering a device with no network connectivity.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Differentiate User EXEC and Privileged EXEC Modes
> User EXEC (indicated by `>`) permits non-disruptive monitoring. The `enable` command transitions to Privileged EXEC (indicated by `#`), granting access to full device diagnostics and configuration commands.

Forms the security boundary between everyday monitoring and administrative management.

```cisco
Switch> enable
Switch# show version
Switch# show privilege
Switch# disable
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show privilege` | Verify operational status, administrative flags, and active state |

```cisco
Device# show privilege
! Confirm operational readiness and healthy state
```

### Explore the Command Landscape with Context-Sensitive Help
> Typing `?` displays available commands per mode; typing `sh?` lists keywords beginning with 'sh'.

Essential for discovering syntax variations and parameters directly on the live CLI.

<WarningBox>
  Always verify that configuration changes are committed to NVRAM using 'copy running-config startup-config'. Mismatched parameters, unassigned VLANs, or missing 'no shutdown' commands will disrupt link forwarding.
</WarningBox>
