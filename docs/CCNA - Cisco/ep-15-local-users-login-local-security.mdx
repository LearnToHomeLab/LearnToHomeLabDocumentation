## Learning Objectives
1. Create Local User Accounts with Hashed Secrets
2. Migrate Management Lines to 'login local'

### Create Local User Accounts with Hashed Secrets
> Provision unique credentials using `username <name> privilege 15 secret <pass>` in global configuration mode.

Enforces non-repudiation and role-based access control.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Migrate Management Lines to 'login local'
> Apply `login local` under `line con 0` and `line vty 0 15` to instruct the CLI to query the local username database.

Replaces vulnerable shared line passwords with individualized authentication.

```cisco
Switch# configure terminal
Switch(config)# username admin privilege 15 secret SuperAdminKey#1
Switch(config)# line con 0
Switch(config-line)# login local
Switch(config-line)# exit
Switch(config)# line vty 0 15
Switch(config-line)# login local
Switch(config-line)# end
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show running-config | include username` | Verify operational status, administrative flags, and active state |

```cisco
Device# show running-config | include username
! Confirm operational readiness and healthy state
```
