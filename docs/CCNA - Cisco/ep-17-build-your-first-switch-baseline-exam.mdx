## Build Your First Switch Baseline (Exam)
In this episode, we focus on **Build Your First Switch Baseline (Exam)**. We examine the core networking principles, Cisco IOS CLI syntax, verification show commands, and common troubleshooting traps according to the official CCNA 200-301 certification blueprint.

<InfoBox emoji="ℹ️" title="Throughout this course">

## Learning Objectives
1. Synthesize Complete Device Management Baseline
2. Enforce Multi-Line Security Controls
3. Perform Final Baseline Verification and NVRAM Commit

### Synthesize Complete Device Management Baseline
> Integrate hostname, MOTD legal banner, enable secret, local admin account, and encrypted passwords.

Standard staging template executed on every switch before rack deployment.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Enforce Multi-Line Security Controls
> Lock console and all 16 VTY lines using `login local`, `exec-timeout 5 0`, and `logging synchronous`.

Prevents unauthorized local physical access and remote session hijacking.

```cisco
Switch# configure terminal
Switch(config)# hostname SW-ACCESS-BASE01
SW-ACCESS-BASE01(config)# enable secret CiscoSecureCCNA!2026
SW-ACCESS-BASE01(config)# username netadmin privilege 15 secret AdminKey#99
SW-ACCESS-BASE01(config)# service password-encryption
SW-ACCESS-BASE01(config)# banner motd #AUTHORIZED ACCESS ONLY#
SW-ACCESS-BASE01(config)# line con 0
SW-ACCESS-BASE01(config-line)# login local
SW-ACCESS-BASE01(config-line)# exec-timeout 5 0
SW-ACCESS-BASE01(config-line)# logging synchronous
SW-ACCESS-BASE01(config-line)# line vty 0 15
SW-ACCESS-BASE01(config-line)# login local
SW-ACCESS-BASE01(config-line)# exec-timeout 5 0
SW-ACCESS-BASE01(config-line)# logging synchronous
SW-ACCESS-BASE01(config-line)# end
SW-ACCESS-BASE01# copy run start
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show running-config` | Verify operational status, administrative flags, and active state |

```cisco
Device# show running-config
! Confirm operational readiness and healthy state
```

### Perform Final Baseline Verification and NVRAM Commit
> Audit the running configuration and execute `copy running-config startup-config`.

Guarantees complete disaster recovery readiness upon power failure.

<WarningBox>
  Always verify that configuration changes are committed to NVRAM using 'copy running-config startup-config'. Mismatched parameters, unassigned VLANs, or missing 'no shutdown' commands will disrupt link forwarding.
</WarningBox>
