## Hub-and-Spoke Static Routing (Exam)
In this episode, we focus on **Hub-and-Spoke Static Routing (Exam)**. We examine the core networking principles, Cisco IOS CLI syntax, verification show commands, and common troubleshooting traps according to the official CCNA 200-301 certification blueprint.

<InfoBox emoji="ℹ️" title="Throughout this course">

## Learning Objectives
1. Master Hub-and-Spoke Static Routing (Exam) Routing Architecture & Path Selection
2. Configure Hub-and-Spoke Static Routing (Exam) on Cisco Routers and Layer 3 Switches
3. Troubleshoot Routing Loops and Asymmetric Drops

### Master Hub-and-Spoke Static Routing (Exam) Routing Architecture & Path Selection
> Analyze how routers evaluate routing tables, longest prefix match logic, administrative distance, and link-state OSPF algorithms.

Enables reliable inter-VLAN routing, multi-router backbone transit, and Internet default gateway reachability.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Configure Hub-and-Spoke Static Routing (Exam) on Cisco Routers and Layer 3 Switches
> Deploy static routes, switch virtual interfaces (SVIs), OSPF single-area processes, or IPv6 unicast forwarding syntax.

Provisions scalable, deterministic packet forwarding across multi-site enterprise topologies.

```cisco
! Routing configuration
Router(config)# router ospf 1
Router(config-router)# network 10.0.0.0 0.255.255.255 area 0
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show ip route` | Verify operational status, administrative flags, and active state |

```cisco
Device# show ip route
! Confirm operational readiness and healthy state
```

### Troubleshoot Routing Loops and Asymmetric Drops
> Trace next-hop reachability, diagnose missing network advertisements, and verify neighbor adjacencies.

Required to resolve packet blackholes, routing loops, and dynamic protocol peering drops.

<WarningBox>
  Always verify that configuration changes are committed to NVRAM using 'copy running-config startup-config'. Mismatched parameters, unassigned VLANs, or missing 'no shutdown' commands will disrupt link forwarding.
</WarningBox>
