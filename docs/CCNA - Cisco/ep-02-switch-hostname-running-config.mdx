### Configure System Hostname According to RFC and Enterprise Naming Standards
> The `hostname <name>` global configuration command defines system identity across CLI prompts, syslog events, and CDP neighbors.

Applied as the foundational step to identify physical switches in racks, CLI prompts, and syslog output.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Inspect Active Dynamic State in Volatile DRAM
> The running-config represents the immediate, operational state running in volatile memory.

Audited using `show running-config` or pipe filters like `show running-config | include hostname` to confirm active settings before saving.

```cisco
Switch# configure terminal
Switch(config)# hostname SW-CAMPUS-ACC01
SW-CAMPUS-ACC01(config)# end
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show running-config | include hostname` | Verify operational status, administrative flags, and active state |

```cisco
Device# show running-config | include hostname
! Confirm operational readiness and healthy state
```
