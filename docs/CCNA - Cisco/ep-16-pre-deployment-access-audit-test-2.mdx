### Audit Management Plane Hardening
> Verify that all console and VTY lines enforce `login local`, synchronous logging, and strict inactivity timeouts.

Pre-flight security checklist before connecting switches to enterprise LANs.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Deploy 'service password-encryption' to Obfuscate Passwords
> `service password-encryption` applies a Type 7 reversible cipher to cleartext line passwords.

Prevents casual observation of passwords in configuration dumps.

```cisco
Switch# configure terminal
Switch(config)# service password-encryption
Switch(config)# line con 0
Switch(config-line)# exec-timeout 5 0
Switch(config-line)# login local
Switch(config-line)# line vty 0 15
Switch(config-line)# exec-timeout 5 0
Switch(config-line)# login local
Switch(config-line)# end
Switch# copy run start
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show running-config | section line` | Verify operational status, administrative flags, and active state |

```cisco
Device# show running-config | section line
! Confirm operational readiness and healthy state
```

### Validate Remote Authentication and Save Final Baseline
> Test authentication from remote terminals and commit changes to NVRAM with `copy run start`.

Ensures compliance and persistence across production maintenance windows.

<WarningBox>
  Always verify that configuration changes are committed to NVRAM using 'copy running-config startup-config'. Mismatched parameters, unassigned VLANs, or missing 'no shutdown' commands will disrupt link forwarding.
</WarningBox>
