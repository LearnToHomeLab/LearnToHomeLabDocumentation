### Compare Cisco Hardware Memory Architecture (RAM, NVRAM, Flash, ROM)
> RAM stores running-config; NVRAM stores startup-config; Flash stores IOS images and `vlan.dat`.

Essential for understanding where network state survives power cycles.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Commit Changes with 'copy running-config startup-config'
> Copies the active RAM configuration to NVRAM so it reloads on bootup.

Mandatory standard operating procedure following any verified change window.

```cisco
Switch# copy running-config startup-config
Destination filename [startup-config]? [Enter]
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show startup-config` | Verify operational status, administrative flags, and active state |

```cisco
Device# show startup-config
! Confirm operational readiness and healthy state
```
