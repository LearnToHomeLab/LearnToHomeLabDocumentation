## Learning Objectives
1. Differentiate Physical Carrier Detect (Status) and Line Protocol
2. Control Administrative State with shutdown and no shutdown

### Differentiate Physical Carrier Detect (Status) and Line Protocol
> `Status` indicates Layer 1 electrical/optical signal; `Protocol` indicates Layer 2 framing and keepalives.

Used to pinpoint whether a link failure is physical cabling (L1) or config/clocking (L2).

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Control Administrative State with shutdown and no shutdown
> `shutdown` places the interface in administratively down state; `no shutdown` enables it.

Standard procedure to bring new endpoints online or isolate misbehaving ports.

```cisco
Switch# configure terminal
Switch(config)# interface GigabitEthernet0/1
Switch(config-if)# description Connection-to-PC1
Switch(config-if)# no shutdown
Switch(config-if)# end
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show ip interface brief` | Verify operational status, administrative flags, and active state |

```cisco
Device# show ip interface brief
! Confirm operational readiness and healthy state
```
