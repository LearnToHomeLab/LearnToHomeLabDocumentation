### Explain Legal Notice Requirements for Network Infrastructure
> Banners must warn that unauthorized access is strictly prohibited and monitored.

Prevents attackers from claiming authorized access in legal prosecution proceedings.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Configure MOTD Banners using the Delimiter Syntax
> The `banner motd <char>` command encloses multi-line text between matching delimiter tokens (e.g. #).

Standard security hardening applied across all routers, switches, and firewalls.

```cisco
Switch# configure terminal
Switch(config)# banner motd #
****************************************************
* AUTHORIZED ACCESS ONLY. ALL SESSIONS MONITORED.  *
* VIOLATORS WILL BE PROSECUTED.                    *
****************************************************#
Switch(config)# end
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show running-config | section banner motd` | Verify operational status, administrative flags, and active state |

```cisco
Device# show running-config | section banner motd
! Confirm operational readiness and healthy state
```

### Verify Banner Injection in the Running Configuration
> Confirm the banner string displays accurately in `show running-config | section banner`.

Ensures the legal notice renders correctly across terminal sessions.

<WarningBox>
  Always verify that configuration changes are committed to NVRAM using 'copy running-config startup-config'. Mismatched parameters, unassigned VLANs, or missing 'no shutdown' commands will disrupt link forwarding.
</WarningBox>
