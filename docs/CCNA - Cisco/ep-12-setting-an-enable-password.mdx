### Configure Privileged Access using 'enable password'
> The legacy `enable password <string>` command protects entry to Privileged EXEC mode.

Maintained for backward compatibility on legacy Cisco devices.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Examine Configuration Dumps and Cleartext Exposure
> `enable password` stores secrets in unencrypted plaintext in the running-config file.

Demonstrates vulnerability to shoulder surfing and compromised backup dumps.

```cisco
Switch# configure terminal
Switch(config)# enable password CiscoLegacyPass123
Switch(config)# end
Switch# disable
Switch> enable
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show running-config | include enable` | Verify operational status, administrative flags, and active state |

```cisco
Device# show running-config | include enable
! Confirm operational readiness and healthy state
```
