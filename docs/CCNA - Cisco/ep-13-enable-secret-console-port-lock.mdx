### Implement Strong Password Hashing with 'enable secret'
> `enable secret <pass>` stores passwords as one-way hashes (MD5, SHA-256, or Scrypt).

Industry standard requirement for securing the Privileged EXEC mode boundary.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Secure Physical Line Console Access (line con 0)
> Configuring a password and `login` under line con 0 forces credential checks on physical console cables.

Secures network hardware against unauthorized on-site physical terminal attachment.

```cisco
Switch# configure terminal
Switch(config)# enable secret CiscoSecure!2026
Switch(config)# line con 0
Switch(config-line)# password ConsoleLock#1
Switch(config-line)# login
Switch(config-line)# exec-timeout 5 0
Switch(config-line)# logging synchronous
Switch(config-line)# end
```
