### Audit a Misconfigured Switch Baseline
> Inspect active configuration, interface line states, and VLAN allocations to detect configuration discrepancies.

Conducted during network staging, site turn-ups, and practical exam challenges.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Correct Device Hostname to Enterprise Naming Standard
> Deploy the correct `hostname <name>` command to align prompt identity with corporate standards.

Establishes accurate switch identification across monitoring tools and logs.

```cisco
Switch# configure terminal
Switch(config)# hostname SW-FLOOR1
SW-FLOOR1(config)# vlan 10
SW-FLOOR1(config-vlan)# name Accounting
SW-FLOOR1(config-vlan)# exit
SW-FLOOR1(config)# interface GigabitEthernet0/1
SW-FLOOR1(config-if)# switchport mode access
SW-FLOOR1(config-if)# switchport access vlan 10
SW-FLOOR1(config-if)# no shutdown
SW-FLOOR1(config-if)# end
SW-FLOOR1# copy run start
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show interfaces status` | Verify operational status, administrative flags, and active state |

```cisco
Device# show interfaces status
! Confirm operational readiness and healthy state
```

### Provision Required Broadcast Domains in the VLAN Database
> Instantiate missing department VLANs and assign appropriate descriptive tags.

Prepares the access layer for host IP segmentation.

### Restore Administratively Disabled Desk Ports
> Locate the disabled access port, assign it to the required VLAN, and bring it up with `no shutdown`.

Restores network connectivity to user workstations.

### Commit Baseline Configuration to NVRAM
> Execute `copy run start` to ensure the repaired baseline configuration persists across reboots.

Guarantees operational continuity in production environments.

<WarningBox>
  Always verify that configuration changes are committed to NVRAM using 'copy running-config startup-config'. Mismatched parameters, unassigned VLANs, or missing 'no shutdown' commands will disrupt link forwarding.
</WarningBox>
