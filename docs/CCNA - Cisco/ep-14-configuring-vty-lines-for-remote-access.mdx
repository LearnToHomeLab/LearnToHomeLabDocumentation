### Configure Remote Access on Virtual Terminal (VTY) Lines
> Access `line vty 0 15` on switches or `line vty 0 4` on routers to manage inbound remote sessions.

Enables administrative management over IP networks.

<InfoBox emoji="📌" title="Key Exam Concept">
  Review protocol interactions, default timers, and packet/frame header fields before deploying this feature in production.
</InfoBox>

### Apply Shared VTY Passwords and Inactivity Timeouts
> Configure `password <pass>`, enable `login`, and set `exec-timeout 10 0` to disconnect abandoned sessions.

Secures remote access lines and prevents session hijacking.

```cisco
Switch# configure terminal
Switch(config)# line vty 0 15
Switch(config-line)# password RemoteVtyPass!99
Switch(config-line)# login
Switch(config-line)# exec-timeout 10 0
Switch(config-line)# logging synchronous
Switch(config-line)# end
```

| Verification Command | Purpose & Key Output Fields to Inspect |
| :--- | :--- |
| `show running-config | section line vty` | Verify operational status, administrative flags, and active state |

```cisco
Device# show running-config | section line vty
! Confirm operational readiness and healthy state
```
