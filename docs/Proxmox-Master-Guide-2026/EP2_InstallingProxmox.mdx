## What You Need

1. Download Etcher, which makes your USB device a bootable ISO [here](https://etcher.balena.io/)
2. Download the latest version of Proxmox VE [here](https://www.proxmox.com/en/downloads)
3. A USB stick to flash Proxmox to

Please watch the video above which covers everything you need to know about installing Proxmox 9, but below is the command you need to validate the hash of the Proxmox file:

Remember, go to the file location of your Proxmox download, right click in there and select "open in terminal"

<DocImage folder="images/EP1_IntroductionToProxmox92026" name="open in  terminal.png" alt="proxmox homelab topology" />

Then paste the command below, and start to type the first three letters of the Proxmox file name then click your tab key on your keyboard, and it will autocomplete!
```
certUtil -hashfile (your file name goes here) SHA256
```
