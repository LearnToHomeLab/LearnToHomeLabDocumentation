## Top Recommendation 

Obsidian is one of the most popular note taking applications out there. We recommend Obsidian due to its flexibility and support for markdown. Markdown offers a lot of flexibility in note creation, you can add code blocks, videos, warnings, drop downs, 
and so much more to your notes. 

You can checkout Obsidian [Here](https://obsidian.md/)

## Common Alternatives

Other common alternatives that others use include: 

1. [Google Keep](https://play.google.com/store/apps/details?id=com.google.android.keep&hl=en_US)
