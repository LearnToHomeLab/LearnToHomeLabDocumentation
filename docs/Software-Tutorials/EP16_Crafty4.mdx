# Install Crafty4 on TrueNAS 2026

In this video we will cover how to install Crafty4 on your TrueNAS Scale device.  

## Creating Datasets

In order for Crafty4 to run on TrueNAS, it requires datasets for the following:

1.  Crafty 4 Config Storage
2.  Crafty 4 Servers Storage
3.  Crafty 4 Logs Storage
4.  Crafty 4 Backups Storage
5.  Crafty 4 Import Storage

So go ahead and log into your TrueNAS machine and head over to the datasets tab on the left:

<DocImage folder="images/EP16_Crafty4" name="image 1.png" alt=" " />

We will then create a new dataset by clicking the _Add Dataset_ blue button on the right. You can just call this Crafty4 and leave it as generic.

<DocImage folder="images/EP16_Crafty4" name="image 2.png" alt=" " />

We will now create a dataset for the five mentioned datasets above in here.

:::info
Pay close attention, after you create a dataset, ensure you select the _Crafty4_ dataset before clicking the blue _add dataset_ button again. This ensures all five of your datasets are contained within the main _Crafty4_ dataset root folder.
:::

<DocImage folder="images/EP16_Crafty4" name="image 3.png" alt=" " />

Every time you create the give datasets, they can all be left as generic, just ensure you name that as mentioned above (config storage, servers storage, logs storage, backups storage, import storage).

<DocImage folder="images/EP16_Crafty4" name="image 4.png" alt=" " />

## Setting Permissions for the Dataset

Now we need to give the proper permissions for the dataset so the app creation will work. Select the _Crafty4_ dataset from the top, then click _edit_ from the permissions section:

<DocImage folder="images/EP16_Crafty4" name="image 5.png" alt=" " />

Select _User_ and find _root_ if not selected already, and then under _Group_ find _apps_ and ensure both have their _Apply_ (apply may show up as 568 after selected) box checked right below them. Also ensure that for access mode, all three are checked for _user_ and _groups_ but not for _other._ After that, ensure you select the boxes under _advanced_ for applying the permissions recursively and for child datasets, than click save.

<DocImage folder="images/EP16_Crafty4" name="image 6.png" alt=" " />

You can then check each sub-dataset, and ensure you see the permissions for _apps_ exists with read, write, and execute.

<DocImage folder="images/EP16_Crafty4" name="image 7.png" alt=" " />

## Installing Crafty4

Now, select the _Apps_ page from the left menu and then select _Discover Apps_ from the top right:

<DocImage folder="images/EP16_Crafty4" name="image 8.png" alt=" " />

Search for Crafty4 in the search bar and select it:

<DocImage folder="images/EP16_Crafty4" name="image 9.png" alt=" " />

Then select _Install_ on it:

<DocImage folder="images/EP16_Crafty4" name="image 10.png" alt=" " />

We will now need to change the following settings:

1.  _Application: Name_ set to what you desire
2.  _Timezone:_ set to your local timezone
3.  _Host IP_: Just select add at the top.
<DocImage folder="images/EP16_Crafty4" name="image 22.png" alt=" " />
4.  We then need to add _Additional Ports_ for Minecraft Java (25565 TCP) and for Bedrock (19132 UDP)  
    Scroll down to _Storage Configuration_
<DocImage folder="images/EP16_Crafty4" name="image 23.png" alt=" " />
5.  Set the storage configurations to your datasets based on names we created earlier in the datasets tab.  
    Scroll down to _Resource Configuration_
<DocImage folder="images/EP16_Crafty4" name="image 24.png" alt=" " />
6.  Set the _CPU_ and _Memory_ to your desired amount. We recommend setting CPU to 4 and Memory to at least 8192.
7.  Then Click Install.
<DocImage folder="images/EP16_Crafty4" name="image 25.png" alt=" " />
## Access Your Crafty4 Dashboard 

To access your Crafty4 Dashboard, you will type the following into your browser. If you do not know your TrueNAS devices IP, that can be found on the dashboard tabs main page:

```
https://<TrueNAS_IP>:30146
```

Here is the landing page for Crafty, the default username is _Admin_ but the password is autogenerated, so let me show you how to find that:

<DocImage folder="images/EP16_Crafty4" name="image 11.png" alt=" " />

The admin password will be saved here:

```
cat /crafty/app/config/default-creds.txt
```

Head back over to your Crafty application, and select the shell:

<DocImage folder="images/EP16_Crafty4" name="image 12.png" alt=" " />

Perform the following command (you can do <kbd>ctrl + shift + V</kbd> to paste the command into the terminal):

```
cat /crafty/app/config/default-creds.txt
```

You will then get an output like so, ho ahead and copy this content to somewhere for safekeeping:

:::info
To copy out of the TrueNAS Scale Container Shell you will highlight the text in the CLI, then click the following two keys on your keyboard: <kbd>CTRL + Ins</kbd> The insert (ins) key is usually found above the arrow keys on a full sized keyboard.
:::

<DocImage folder="images/EP16_Crafty4" name="image 13.png" alt=" " />

```
"username": "admin",
    "password": "CVgBELR20&hOnLnGaaG4rOfJ$bs6NKdYqnxD7U7SJu&DiAA1@*4A%3ZZjZzmeQY4",
    "info": "This is NOT where you change your password. This file is only a means to give you a default password."
```

You can then paste that content into your Crafty dashboard and login:

<DocImage folder="images/EP16_Crafty4" name="image 14.png" alt=" " />

Here is the default login screen, and the red box shows where you can create a

<DocImage folder="images/EP16_Crafty4" name="image 15.png" alt=" " />

Then fill out the settings based on your preferences and select _build server_:

<DocImage folder="images/EP16_Crafty4" name="image 16.png" alt=" " />

Then from this screen, under actions, click the _play_ or _start_ button:

<DocImage folder="images/EP16_Crafty4" name="image 17.png" alt=" " />

To edit your Minecraft server settings, just click the name of your server:

<DocImage folder="images/EP16_Crafty4" name="image 18.png" alt=" " />

Here you can see all the key areas you may need to access to administrate your server:

<DocImage folder="images/EP16_Crafty4" name="image 19.png" alt=" " />

Wait a couple of minutes for your server files to download and install, then you will be presented with your server and the status column showing as online. Open Minecraft, connect to your TrueNAS Scale IP and port number depending on your Minecraft server type (25565 or 19132) and start having fun!

<DocImage folder="images/EP16_Crafty4" name="image 20.png" alt=" " />

There you have it, we are in!

<DocImage folder="images/EP16_Crafty4" name="image 21.png" alt=" " />
