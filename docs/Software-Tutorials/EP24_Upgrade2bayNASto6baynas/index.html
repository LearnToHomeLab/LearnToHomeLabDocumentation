Upgrading from a 2-Bay UGREEN NAS to a 6-Bay ZimaCube 2 Without Losing Data

Upgrading your NAS doesn't necessarily mean starting over. In this project, I upgraded my existing TrueNAS setup from a 2-bay UGREEN NAS to a 6-bay ZimaCube 2 while preserving my existing storage pools, configuration, accounts, and settings.

Rather than rebuilding everything from scratch, I migrated my existing TrueNAS installation to the new hardware. This meant I could expand my storage capacity without having to recreate users, permissions, shares, and other configurations.

In this guide, I'll walk through the process of preparing the old NAS, creating a bootable TrueNAS installation USB, installing TrueNAS on the ZimaCube 2, transferring the hard drives, and restoring the configuration from the original system.

Why Upgrade to a 6-Bay NAS?​

My original NAS was a 2-bay UGREEN system running TrueNAS. While it worked well for my homelab, I eventually needed more storage capacity and flexibility.

The ZimaCube 2 provides six hard drive bays, giving me additional room to expand my storage as my homelab continues to grow.

The goal was to migrate the existing setup rather than build an entirely new NAS. I wanted to keep the storage pools and configuration I had already spent time setting up.

What You'll Need​

Before starting the migration, gather the following:

  • Your existing NAS running TrueNAS
  • A new server/NAS device
  • A USB flash drive for the TrueNAS installer
  • balenaEtcher to create the bootable USB drive
  • The TrueNAS installation image
  • Your existing NAS hard drives
  • Access to the TrueNAS web interface

Important: Make sure you have a current backup of your TrueNAS configuration and, ideally, a separate backup of any irreplaceable data. Moving drives between systems is not a substitute for having a backup.

Step 1: Export Your TrueNAS Configuration​

Before shutting down the old UGREEN NAS, I first exported my existing TrueNAS configuration.

This is one of the most important steps in the migration. The configuration backup contains the settings needed to restore much of the existing TrueNAS environment, including user accounts, permissions, network configuration, and storage-related settings.

I accessed the TrueNAS web interface on the old NAS and downloaded the configuration backup.

Make sure you save this file somewhere other than the drives you're about to move. You'll need access to it during the restoration process.

You will download your configuration file from: system / Advanced Settings then on the top right you will see a drop down manage configuration then select download file and ensure * Export Password Secret Seed* is selected, then click save

Now you can turn the NAS off by shutting it down from the power button in the top right of the TrueNAS GUI interface.

Step 2: Download TrueNAS and Create a Bootable USB​

With the configuration safely backed up, the next step is to prepare the installation media for the ZimaCube 2.

First, download the TrueNAS installation image from the official TrueNAS website:

Download TrueNAS

Next, download and install balenaEtcher:

Download balenaEtcher

Using balenaEtcher, create a bootable USB installer:

  1. Insert your USB flash drive into your computer.
  2. Open balenaEtcher.
  3. Select the downloaded TrueNAS image.
  4. Select your USB flash drive as the target.
  5. Start the flashing process.
  6. Wait for Etcher to finish writing and verifying the image.

Once the process is complete, you have a bootable TrueNAS installation USB ready for the new NAS.

Step 3: Install TrueNAS on the ZimaCube 2​

Now that the installation USB is ready, it's time to prepare the new hardware.

I connected the bootable USB drive to the ZimaCube 2 and booted the system into the TrueNAS installer.

From there, I proceeded through the TrueNAS installation process, selecting the appropriate boot device for the operating system installation.

The important thing here is to install TrueNAS on the intended boot device inside the new NAS, not on the existing data drives that will be migrated.

After the installation completed, I rebooted the ZimaCube 2 and accessed the TrueNAS web interface to verify that the new system was running correctly.

At this stage, the new NAS has a fresh TrueNAS installation, but it does not yet contain my original storage pools or configuration.

Step 4: Shut Down the Old UGREEN NAS and Move the Hard Drives​

With the new ZimaCube 2 running TrueNAS, it was time to transfer the existing storage.

I shut down the original UGREEN NAS properly before removing any of the hard drives.

Once the system was powered off, I removed the existing drives from the UGREEN NAS and installed them into the ZimaCube 2.

Because these drives contain my existing TrueNAS storage pools, it's important not to initialize, format, or create new pools on them.

The goal is to bring the existing ZFS storage into the new system intact.

After installing the drives into the ZimaCube 2, I powered the system back on.

Step 5: Restore the TrueNAS Configuration​

With the drives transferred and the new NAS running, the next step was restoring the configuration backup I exported earlier.

I accessed the TrueNAS web interface on the ZimaCube 2 and imported the saved configuration from my original UGREEN NAS.

You will again just go into system / advanced settings / manage configuration and instead of download, you will upload the .tar file.

Step 6: Verify the Storage Pools and Configuration​

After restoring the configuration, I checked that my existing storage pools and data were available on the new NAS.

I also verified that my existing TrueNAS accounts and settings had been restored.

The end result was that my ZimaCube 2 was running the same TrueNAS environment I had previously used on the UGREEN NAS, but with six drive bays available instead of two.

This made the upgrade much quicker than rebuilding the entire NAS from scratch.

As with any storage migration, it's important to verify that the pools are healthy and that your data is accessible before considering the process complete.

The Final Result​

I successfully moved from my 2-bay UGREEN NAS to the 6-bay ZimaCube 2 while retaining my existing TrueNAS configuration and data pools.

The process involved:

  • Exporting the original TrueNAS configuration
  • Creating a bootable TrueNAS USB installer using balenaEtcher
  • Installing TrueNAS on the ZimaCube 2
  • Shutting down the old UGREEN NAS
  • Transferring the existing hard drives
  • Restoring the original TrueNAS configuration
  • Verifying that the storage pools, accounts, and settings were available

The biggest advantage of this process was that I didn't have to rebuild my NAS from scratch. I was able to upgrade the hardware while keeping the environment I had already configured.

If you're running TrueNAS on a smaller NAS and want to upgrade to a larger system, migrating your existing configuration and storage pools can make the transition significantly easier.
